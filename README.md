# Железно! 🔥

Интернет-магазин авторского декора из металла ручной работы, Минск.
Подсвечники, светильники, столы, скамейки, кормушки, ложки для обуви и арт-объекты для интерьера и сада.

## Что есть на сайте

- Каталог с фильтром «Для интерьера / Для сада» и окном товара
- Заказ товара: короткая форма или кнопки Telegram / Viber / WhatsApp
- Подробная форма «Изготовление на заказ»: размеры, цвет, бюджет, до 3 фото
- Разделы «О мастере», «Доставка и оплата», «Контакты»
- Тёмный лофт-дизайн, работает на телефонах

## Структура

```
index.html                 — страница сайта
css/style.css              — оформление
js/config.js               — ⚙️ контакты, телефон, Telegram, адрес для заявок
js/products.js             — 🛒 товары (названия, цены, фото)
js/app.js                  — логика сайта
images/products/           — сюда класть фото товаров
worker/telegram-worker.js  — пересылка заявок в Telegram
```

## Как поменять контакты

Откройте `js/config.js` и впишите свой телефон, ник в Telegram, часы работы.

## Как добавить или изменить товар

1. Положите фото в `images/products/`, например `bench-1.jpg`.
2. В `js/products.js` скопируйте любой блок `{ ... }` и поменяйте данные:
   ```js
   images: ["images/products/bench-1.jpg", "images/products/bench-2.jpg"],
   price: 520,
   ```
   Если `images: []`, вместо фото показывается рисованная заглушка.

## Как получать заявки в Telegram

Пока адрес `orderEndpoint` в `config.js` пустой, форма открывает WhatsApp с готовым текстом заявки.
Чтобы заявки приходили прямо в Telegram (вместе с фото):

1. В Telegram напишите **@BotFather**, отправьте `/newbot` и сохраните **токен**.
2. Напишите своему новому боту любое сообщение.
3. Узнайте свой **chat id** у бота **@userinfobot**.
4. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com), это бесплатно.
   Откройте **Workers & Pages → Create → Worker**, вставьте код из `worker/telegram-worker.js` и нажмите Deploy.
5. В настройках Worker откройте **Settings → Variables and Secrets** и добавьте:
   - `BOT_TOKEN` с типом **Secret** (токен из шага 1)
   - `CHAT_ID` (из шага 3)
   - `ALLOWED_ORIGIN` (адрес вашего сайта, например `https://mishpip31-droid.github.io`)
6. Скопируйте адрес Worker (`https://....workers.dev`) в `orderEndpoint` в `js/config.js`.

Токен бота не хранится на сайте, поэтому посторонние его не увидят.

## Как опубликовать (бесплатно, GitHub Pages)

В репозитории откройте **Settings → Pages**, в разделе **Source** выберите ветку и папку `/ (root)`, затем нажмите Save.
Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/MyShop/`.

## Посмотреть локально

Просто откройте `index.html` в браузере.
